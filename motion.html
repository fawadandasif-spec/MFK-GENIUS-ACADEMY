Motion

Learn motion, distance, displacement, speed, velocity, acceleration and equations of motion.

1. What is Motion?

Motion is the change in position of an object with respect to time.

An object is said to be in motion when its position changes relative to a reference point.

2. Rest and Motion

An object is at rest when its position does not change with respect to a reference point.

An object is in motion when its position changes with respect to a reference point.

3. Distance

Distance is the total length of the path travelled by an object.

  • Distance is a scalar quantity.
  • It has magnitude only.
  • SI unit is metre (m).

4. Displacement

Displacement is the shortest straight-line distance from the initial position to the final position, along with direction.

  • Displacement is a vector quantity.
  • It has magnitude and direction.
  • SI unit is metre (m).
Displacement ≤ Distance

5. Speed

Speed is the distance travelled by an object per unit time.

Speed = Distance ÷ Time

SI unit of speed is m/s.

Example

If an object travels 100 m in 20 s:

Speed = 100 ÷ 20 = 5 m/s

6. Velocity

Velocity is the displacement of an object per unit time.

Velocity = Displacement ÷ Time

Velocity is a vector quantity and its SI unit is m/s.

7. Acceleration

Acceleration is the rate of change of velocity with respect to time.

a = (v - u) ÷ t

Where:
u = initial velocity
v = final velocity
t = time

8. Types of Motion

  • Translational Motion – object moves from one place to another.
  • Rotational Motion – object rotates around an axis.
  • Circular Motion – object moves along a circular path.
  • Vibratory Motion – object moves repeatedly to and fro.

9. Equations of Motion

For uniformly accelerated motion, three important equations are used.

v = u + at
s = ut + ½at²
v² = u² + 2as

Where:
u = initial velocity
v = final velocity
a = acceleration
t = time
s = displacement

10. Uniform and Non-Uniform Motion

Uniform motion: An object covers equal distances in equal intervals of time.

Non-uniform motion: An object covers unequal distances in equal intervals of time.

11. Numerical Example

Question

A car starts from rest and accelerates at 2 m/s² for 5 seconds. Find its final velocity.

Given:

u = 0 m/s
a = 2 m/s²
t = 5 s

Formula:

v = u + at

Calculation:

v = 0 + (2 × 5)

v = 10 m/s

Answer: Final velocity = 10 m/s

12. Quick Revision

  • Motion = change in position with time.
  • Distance is a scalar quantity.
  • Displacement is a vector quantity.
  • Speed = Distance ÷ Time.
  • Velocity = Displacement ÷ Time.
  • Acceleration = Change in velocity ÷ Time.
  • v = u + at
  • s = ut + ½at²
  • v² = u² + 2as
